Sobre — ALIEN THREAT

Projeto Primata Games em 2026.

ALIEN THREAT: Pilote um disco voador sobre uma cidade procedural viva, agora com serviços urbanos, fazendas, aeroporto, parque de diversões, instalação secreta, transportes, profissionais, animais e objetos de rua.

RAIO TELEPORT: Segure Espaço para transferir alvos para a nave-mãe. Construções deixam destroços; humanos deixam esqueletos com pequenas variações visuais.

BOOST: Segure X para propulsão de emergência. Cada acionamento contínuo dura no máximo 5 segundos e consome a mesma energia usada pelo raio teleportador. Solte X para armar um novo acionamento.

TIP: Use o boost para cruzar áreas vazias ou escapar do fogo defensivo, mas preserve energia suficiente para abduzir quarteirões densos.
